## Setup Instructions

### 1. Install Python dependencies
```bash
pip install flask flask-cors faiss-cpu sentence-transformers PyMuPDF requests
```

### 2. Add source files
Place PDFs, TXT files, or supported CSV files that you are authorized to process in `data/raw/`. Corpus files and generated indexes are excluded from Git so copyrighted material and derived text are not uploaded.

Use `Bhagwad_Gita.csv` as the Gita source. Keep the old per-chapter Gita `.txt` files out of `data/raw/` so they are not indexed twice.

### 3. Build the FAISS index
```bash
cd KrishnAI-CHATBOT
python build_faiss.py
```
This will print progress for each file and confirm total chunks indexed.

### 4. Start Ollama with LLaMA 3.1
```bash
ollama run llama3.1:8b
```
Leave this running in a separate terminal.

### 5. Start the Flask server
```bash
python server.py
```
The API runs on `http://localhost:5000`.

### 6. Open the frontend
Open `frontend/index.html` directly in your browser, OR access via `http://localhost:5000` (Flask serves it automatically).

## Configuration

In `rag_terminal.py`:
- `OLLAMA_MODEL` — change to any model you have (e.g., `mistral`, `llama3.2`)
- `TOP_K` — number of passages retrieved per query (default: 6)
- `CRISIS_PATTERNS` — add more keywords to expand crisis detection

In `build_faiss.py`:
- `CHUNK_SIZE` / `CHUNK_OVERLAP` — tuning for chunking quality
- `SOURCE_LABELS` — add friendly names for new books you add

The current embedding model does not require a Hugging Face token. Do not put access tokens in source files.

## Crisis Safety

If a user types anything matching crisis keywords (suicidal ideation, self-harm, etc.), the system **immediately returns** a compassionate message with Indian helpline numbers — without calling the LLM. This is a hard gate that cannot be bypassed.

Helplines shown:
- **iCall:** 9152987821
- **Vandrevala Foundation (24/7):** 1860-2662-345
- **IASP Crisis Centres directory**

## Adding More Books

1. Drop the new PDF, TXT, or supported CSV into `data/raw/`
2. Add an entry to `SOURCE_LABELS` in `build_faiss.py` (optional, for a nice display name)
3. Re-run `python build_faiss.py`
4. Restart `server.py`

That's it — no other changes needed.
